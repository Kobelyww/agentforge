# 维修工单管理规范（摘要）

## 1. 工单要素（必填）

| 字段 | 说明 | 示例 |
|---|---|---|
| equipment_id | 设备编号 | AC-017 |
| title | 工单标题 | AC-017 轴承外圈磨损维修 |
| fault_type | 故障类型编码 | bearing_outer_race_wear |
| confidence | 诊断置信度 0–1 | 0.87 |
| priority | P1–P4 | P2 |
| actions | 处置步骤清单 | ["停机断电", "更换轴承"] |
| parts | 备件清单 | ["6205-2RS x2"] |
| estimated_hours | 预计停机小时 | 2 |

## 2. 优先级定义

| 级别 | 定义 | 响应要求 |
|---|---|---|
| P1 | 危及安全/生产线停线 | 立即停机处置 |
| P2 | 劣化加速，24h 内会恶化 | 24 小时内安排 |
| P3 | 功能未丧失，计划检修 | 纳入周计划 |
| P4 | 观察项 | 持续监测 |

## 3. 闭环要求

1. 工单必须基于**证据**：频谱数据、手册判据或历史案例，置信度 < 0.6 时应先复核
2. 备件出库与工单关联，维修完成后记录实际工时
3. 复机验证：振动 RMS 达标（≤2.8 mm/s）方可关闭工单
4. 诊断-维修-验证全记录归档，用于后续案例库沉淀
