# KA-75 螺杆空压机 操作与维护手册（节选 v3.2）

## 1. 设备概览

| 参数 | 数值 |
|---|---|
| 型号 | KA-75 螺杆空压机 |
| 额定功率 | 75 kW |
| 额定转速 | 2960 r/min（转频 49.33 Hz） |
| 额定排气压力 | 0.8 MPa |
| 主轴承 | 6205-2RS 深沟球轴承 ×2 |
| 润滑方式 | 矿物润滑油 46# |

## 2. 日常点检项目

1. 排气压力与温度（正常 0.75–0.85 MPa / 85–95 ℃）
2. 油位与油质（每 2000 h 更换）
3. 振动速度 RMS（机壳轴承位，见 4.1 判据）
4. 异响（金属敲击/摩擦声立即停机）

## 4. 振动判据与诊断

### 4.1 振动限值（依据 ISO 10816-3，刚性支承）

| 状态 | 振动速度 RMS（mm/s） |
|---|---|
| 良好 | ≤ 2.8 |
| 允许 | 2.8 – 4.5 |
| **报警** | **> 4.5**（应安排停机检查） |
| 危险 | > 7.1（立即停机） |

### 4.2 6205 轴承故障特征频率

在额定转速 2960 r/min（转频 49.33 Hz）下，按轴承几何参数
（滚动体 9 个，滚珠直径 7.94 mm，节圆直径 39.04 mm，接触角 0°）计算：

| 部位 | 特征频率系数（×转频） | 特征频率 |
|---|---|---|
| 外圈（BPFO） | 3.59 | ≈ 176.9 Hz |
| 内圈（BPFI） | 5.41 | ≈ 267.2 Hz |
| 滚动体（BSF） | 2.36 | ≈ 116.3 Hz |
| 保持架（FTF） | 0.40 | ≈ 19.7 Hz |

> 注：轴承外圈出现疲劳剥落时，频谱在 BPFO 处出现明显峰值及其 2×、3× 谐波，
> 且常伴有 1× 转频分量抬升。振幅随劣化进程增长，达到报警限应立即安排更换。

### 4.3 常见频谱特征速查

| 频谱特征 | 可能原因 |
|---|---|
| BPFO 峰值突出 | 外圈磨损/剥落 |
| BPFI 峰值突出 | 内圈磨损（常伴 1× 边带） |
| 1× 转频突出 | 转子不平衡 |
| 2× 转频突出 | 联轴器不对中 |
| 宽带抬升 | 润滑不良/气蚀 |

## 5. 轴承更换作业 SOP（摘要）

1. 停机断电、挂"检修中"警示牌，泄压至 0 MPa
2. 拆卸联轴器护罩与联轴器，做好对中标记
3. 使用专用拉马拆除旧轴承（禁止锤击轴伸）
4. 清洁轴承座，检查轴颈磨损与形位公差
5. 安装新轴承 6205-2RS ×2（加热至 90–110 ℃ 热装）
6. 复查联轴器对中（径向 ≤0.05 mm，角度 ≤0.05 mm/100 mm）
7. 复机试运行 30 min，记录振动 RMS（应 ≤2.8 mm/s）
8. 复机后 24 h 内每 2 h 记录一次振动值

**常用备件**：6205-2RS ×2、轴用挡圈、O 型圈套装。
**预计停机时长**：2 小时（含试运行）。
