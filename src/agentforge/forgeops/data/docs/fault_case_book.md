# 设备故障案例库（选编）

## 案例 CS-2025-018：AC-017 空压机轴承外圈磨损（同型设备）

- **时间**：2025-03
- **现象**：夜班巡检发现 3 号车间空压机异响，机壳轴承位振动报警
- **频谱**：176.9 Hz（BPFO）峰值 6.1 mm/s，伴 2× BPFO 谐波；1× 转频 2.0 mm/s；RMS 4.6 mm/s
- **诊断**：6205 轴承外圈疲劳剥落（与 4.2 节特征频率完全吻合）
- **处置**：P2 工单，停机 2.1 h 更换 6205-2RS ×2，复查对中
- **结果**：复机后 RMS 降至 1.4 mm/s，24 h 趋势平稳
- **经验**：该机型在运行 8000 h 左右进入轴承疲劳期，建议提前备件

## 案例 CS-2025-031：WP-203 水泵联轴器不对中

- **时间**：2025-05
- **现象**：循环水站水泵振动升高，伴周期性"顿挫感"
- **频谱**：2× 转频（49.33 Hz）幅值 4.0 mm/s 为最大谱线，1× 仅 1.5 mm/s
- **诊断**：联轴器不对中（2× 特征典型）
- **处置**：P3 工单，激光对中复查，径向偏差 0.14 mm 超标，重新对中至 0.04 mm
- **结果**：2× 分量降至 0.6 mm/s，RMS 回落至 1.1 mm/s

## 案例 CS-2025-044：AC-023 冷却器结垢导致排气温度高

- **时间**：2025-07
- **现象**：排气温度持续 102 ℃ 超标，振动正常
- **频谱**：无异常谱线（排除机械故障）
- **诊断**：冷却器板间结垢（热阻上升），非机械故障
- **处置**：P3 工单，化学清洗冷却器
- **经验**：温度类异常优先排查热交换路径，振动正常可基本排除机械故障
