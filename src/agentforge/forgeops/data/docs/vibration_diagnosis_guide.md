# 旋转设备振动频谱诊断方法指南

## 1. 为什么做频谱分析

时域振动波形只能给出"总体烈度"（RMS），无法回答"哪里坏了"。
将时域信号做 FFT 变换得到频谱后，每根谱线对应一个物理部件的特征频率，
从而实现**故障定位**。

## 2. 标准分析流程

1. 确认设备转速 n (r/min)，计算转频 f₁ = n / 60
2. 对振动加速度/速度信号做 FFT（建议频率分辨率 ≤1 Hz，采样时长 ≥1 s）
3. 找出幅值最大的前 N 个峰值，换算为"峰值频率 / 转频"的倍数
4. 对照轴承特征频率表（BPFO/BPFI/BSF/FTF）与倍频特征表定位故障
5. 结合幅值判据（ISO 10816）判断劣化程度与处置优先级

## 3. 倍频特征速查

| 谱线位置 | 典型故障 | 处置建议 |
|---|---|---|
| 1× f₁ | 不平衡（转子结垢、磨损） | 动平衡校正 |
| 2× f₁ | 联轴器不对中 | 激光对中复查 |
| 0.4–0.5× f₁ | 转轴裂纹 / 油膜涡动 | 立即检查 |
| BPFO（外圈） | 外圈剥落 | 更换轴承 |
| BPFI（内圈） | 内圈剥落（常伴 1× 边带） | 更换轴承 |
| BSF（滚动体） | 滚动体点蚀 | 更换轴承 |
| 高频宽带抬升 | 润滑不良 / 气蚀 | 润滑管理 / 工况核查 |

## 4. 幅值判据（ISO 10816-3 中型机器，刚性支承）

- RMS ≤ 2.8 mm/s：良好
- 2.8 < RMS ≤ 4.5 mm/s：允许（加密监测）
- 4.5 < RMS ≤ 7.1 mm/s：**报警**（安排停机检查）
- RMS > 7.1 mm/s：危险（立即停机）

## 5. 实践要点

1. 单次频谱异常不构成结论：应结合**趋势**（RMS 是否持续上升）与**历史案例**
2. 谐波结构比单根谱线更可靠：真实故障通常伴随 2×、3× 谐波
3. 负荷与转速变化会改变谱线位置，分析时必须核对当时的运行工况
4. 任何诊断结论都应给出**置信度**与**建议动作**，并落实为维修工单闭环
